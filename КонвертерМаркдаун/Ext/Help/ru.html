Конвертер Markdown в Word (внешняя обработка 1С:Предприятие 8.3)

Обработка конвертирует текст в разметке Markdown — заголовки, списки, таблицы, цитаты, блоки кода, ссылки, картинки — в новый документ Microsoft Word, применяя настраиваемые стили, замены и оформление; результат открывается в Word или сохраняется в файл.

Параметры

  • Текст Markdown — исходный текст; вводится вручную или кнопкой «Загрузить из файла» (.md, .markdown, .txt).
  • Файл результата — путь сохранения; формат по расширению: docx, doc, pdf, rtf, html, txt; пусто — документ только показывается.
  • Показать документ Word — открывать Word после конвертации; включён по умолчанию; при выключенном путь файла обязателен.
  • Базовый каталог — для относительных путей картинок; при загрузке файла проставляется его каталогом автоматически.
  • Шаблон документа — файл .dotx/.doc со стилями организации: колонтитулы, поля, параметры страницы переносятся в каждый новый документ. Для фирменных заголовков укажите в «Стили заголовков» имена стилей из шаблона вместо кодов −2…−7 (по умолчанию используются встроенные стили Word, не зависящие от языка).
  • Замены перед разбором — таблица «что → чем», применяется к тексту до разбора, включая блоки кода; порядок — сверху вниз. По умолчанию: (c) → ©, (r) → ®, (tm) → ™, __текст__ → **текст** (регулярное). Пользователь может добавить свои, например: « → ", » → ", — → -.
  • Математические символы — таблица соответствий LaTeX-команд и Unicode-символов (α, β, ≥, ∈ и т.д.); задана в модуле объекта, расширение — по образцу «Замены».
  • Кодировка исходного файла — определяется автоматически: по BOM; без BOM — эвристикой (допустимость UTF-8) либо ANSI (cp1251).
  • Стили заголовков — соответствие «уровень → стиль Word»; по умолчанию коды −2…−7 (встроенные «Заголовок 1»–«Заголовок 6», не зависят от языка Word); можно указать имя стиля из шаблона.
  • Настоящие списки Word — маркеры и нумерация средствами Word; выключено — текстовые маркеры «•» и сквозная нумерация средствами обработки.
  • Пробелов на уровень вложенности — отступ в исходном тексте на один уровень списка; по умолчанию 2 (табуляция считается за 2 пробела).
  • Шаг отступа списка — отступ одного уровня в Word; по умолчанию 18 пт.
  • Интервал после абзаца — по умолчанию 6 пт; в блоках кода — 0.
  • Максимальная ширина картинок — по умолчанию 450 пт; 0 — не масштабировать.
  • Шрифты — текст: Calibri 11; код (строчный и блоки): Consolas 10.
  • Цвета фона — блок кода и цитата: 242, 242, 242; шапка таблицы: 217, 217, 217; пусто — без заливки.

Результат работы

Результат Что получается Из какой разметки
Заголовки Абзацы со стилями Word «Заголовок 1»–«Заголовок 6» или стилями шаблона Строки с «#»…«######» в начале
Абзацы с разметкой Жирный, курсив, зачёркнутый, строчный код, гиперссылки, картинки с масштабированием **…**, *…*, ~~…~~, `…`, [текст](адрес), ![текст](путь)
Списки Маркированные и нумерованные, вложенность отступом пробелами или табуляцией Строки «- », «* », «+ », «1. », «1) »
Блоки кода Моноширинный шрифт, отступ 14 пт, заливка фоном одним диапазоном на весь блок Текст между строками «```»
Цитаты Отступ 18 пт, курсив, левая линия, заливка фоном; соседние строки «>» объединяются Строки, начинающиеся с «>»
Таблицы Сетка, жирная шапка с заливкой, инлайн-разметка в ячейках, «\|» внутри ячейки не разрезает колонки Строки «| … |» со строкой-разделителем «|---|»
Горизонтальные линии Стандартная линия Word; при недоступности — нижняя граница абзаца «---», «***», «___»
Формулы Упрощённо: LaTeX-команды заменяются Unicode-символами, _{...} и ^{...} — подстрочным/надстрочным начертанием Word; дроби и матрицы не поддерживаются Текст между $…$ или $$…$$
Файл результата Документ сохраняется в формате по расширению пути: .docx, .doc, .pdf, .rtf, .html, .txt; Word 2007 использует резервный вызов сохранения Поле «Файл результата», расширение файла
Файл результата Документ сохраняется в формате по расширению пути; Word 2007 использует резервный вызов сохранения Параметр «Файл результата»

Подсветка и контроль

  • Автозамены Word «при вводе» (умные кавычки, автотире, автосимволы, автосписки, автограницы) отключаются на время конвертации и восстанавливаются после — настройки профиля пользователя не меняются.
  • Незамкнутые маркеры («цена * 5 долларов») остаются обычным текстом: проверяются символы слева и справа от маркера.
  • Недоступная картинка выводится альтернативным текстом в квадратных скобках; некорректный адрес ссылки остаётся обычным текстом.
  • Незакрытый блок кода в конце текста выводится как блок кода.
  • В текстовом режиме списков идиома «1. 1. 1.» нумеруется сквозным счётчиком: 1. 2. 3.

Когда формировать / использовать

  • При подготовке регламентов и инструкций, которые ведутся в Markdown, — получить оформленный документ Word для согласования и печати.
  • При выпуске документов по фирменному бланку — указать шаблон .dotx организации и имена её стилей заголовков: колонтитулы, поля и оформление лягут в каждый документ без ручной правки.
  • При массовом формировании файлов — выключить показ документа и указывать путь файла; формат задаётся расширением (pdf — для рассылки, rtf — для обмена).
  • При конвертации текста с картинками по относительным путям — загрузить исходный файл кнопкой «Загрузить из файла»: базовый каталог проставится сам.
  • Перед передачей обработки пользователям — кнопка «Вставить тестовый текст» и прогон приёмочного сценария (кавычки и автозамены в блоке кода, нумерация, пайп в таблице, недоступная картинка).

Важно понимать

  • Обработка создаёт новые документы; редактирование существующих .docx не поддерживается.
  • Требуется установленный Microsoft Word; серверная автоматизация Word официально не поддерживается Microsoft — вызывайте обработку на клиенте, веб-клиент не подходит (COM (технология подключения к Word) в нём недоступен).
  • Поддерживается: заголовки #..######, **жирный**, *курсив*, `код`, ~~зачеркнутый~~, [ссылки](адрес), ![картинки](путь), списки (маркированные/нумерованные, с вложенностью), цитаты >, блоки кода, таблицы, горизонтальные линии — список совпадает с шапкой модуля обработки.
  • Пересекающиеся и несимметричные комбинации маркеров (например, **жирный *закрытие*) могут дать неверную вложенность — осознанное ограничение упрощённого парсера без стека разделителей.
  • Замены перед разбором действуют на весь текст, включая блоки кода.
  • Относительные пути картинок резолвятся от базового каталога; http(s), file: и абсолютные пути передаются в Word без изменений.
  • Математика рендерится упрощённо (символы и индексы, не объекты-уравнения Word); для полноценного LaTeX (дроби, матрицы, выравнивание) используйте предконвертацию Pandoc.
